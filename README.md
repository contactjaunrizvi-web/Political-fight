# SANSAD FIGHT — playable browser build

Developed by Mohd Jaun Rizvi — Instagram: @jaunrizviii

## Deploy
Upload `index.html` to a GitHub repository and import the repository in Vercel. Choose Framework Preset **Other**, leave Build Command blank, and set Output Directory to `.`.


## Controls
- Player 1: A/D move, W jump, J punch, K kick, B block, L special
- Local Player 2: Left/Right move, Up jump, Num1 punch, Num2 kick, Right Shift block, Num3 special
- Mobile: left joystick, on-screen Punch/Kick/Block/Special buttons

Three.js is loaded from a CDN, so the game requires an internet connection. This build is a compact arcade prototype with procedural fighter visuals; not a AAA production.
